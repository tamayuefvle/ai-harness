# IMP-20260814-03: Isolate planning tests from live product docs

- ID: `IMP-20260814-03`
- Status: `done`
- Date: 2026-08-14
- Owner: human / Cursor

## Problem

After product discovery and stack approval fill `docs/product/*` and resolve profiles, several harness tests still copied those live files or ran `profile:check` against the current checkout. `verify:harness` then failed even though fragment merge succeeded.

## Proposal

Keep shipped planning templates as fixtures for tests. Copy those fixtures into temporary checkouts instead of the live product documents. Run the unresolved `profile:check` skip case against a fixture, not the current repository.

## Acceptance

- Filled product documents do not change planning/discovery/design test outcomes.
- Unresolved `profile:check` skip is proven with a fixture.
- Distribution checkout still matches the fixture snapshot while it ships templates.

## Verification

- `node --test` on the planning, discovery, design, and profile-check test files
- `npm run verify:harness`

## Outcome

v14.9.3 isolates those tests so product overlays can complete planning without breaking harness verification.
