# Improvement record: IMP-20260728-01

## Request

Re-evaluate whether GitHub MCP is useful, account for Cursor/WSL PAT environment
limitations, preserve a useful Docker path when appropriate, and rebuild the v6
harness after approval.

## Classification

- Type: architecture improvement, security, automation, context improvement,
  validation and documentation
- Scale: cross-cutting
- Initial risk: high

## Assumptions

- GitHub is the CI provider.
- The target repository can install GitHub CLI.
- GitHub write operations remain outside the approved scope.
- Docker GitHub MCP is optional and may be unavailable in some environments.

## Research conclusion

- GitHub MCP is useful for conversational exploration but is not required for
  deterministic PR/check/run evidence.
- GitHub CLI provides structured read-only commands and independent login.
- The official Docker MCP supports OAuth, read-only mode, lockdown mode and
  toolset restrictions.

## Approved decision

- Standard: GitHub CLI gateway and normalized report.
- Optional: Docker GitHub MCP with OAuth and restrictive settings.
- Removed: PAT-file launcher and required GitHub MCP configuration.
- Additional repair: Git hook execute permission, harness tests in CI and
  evidence artifact retention.

See `docs/specs/PF-002-github-integration-rebuild/` and ADR-0003.

## Verification

See `verification.md`. Local deterministic checks passed. Target authentication,
real PR workflows, OAuth browser/device flow and image digest verification remain
environment-dependent.

## Review

No unresolved BLOCKER/HIGH finding. The optional image is release-tag pinned but
not digest pinned; it is prohibited from becoming a required control until the
digest is verified and recorded.
