# Add an AWS deployment profile

- ID: `IMP-20260813-03`
- Status: `done`
- Date: 2026-08-13
- Owner: harness maintainer

## Problem

AWS was a valid hosting intent but not a registry profile, so stack selection could not record it.

## Proposal

Add `deployment/aws` (human-operated; no auto-deploy), document workstation/IAM/CLI expectations, and deny common AWS production deploy CLIs without approval.

## Acceptance

- `deployment/aws` is in `harness/profiles/registry.json` and resolves `runtime/node`.
- Docs state that AWS account, IAM, secrets, resource creation, and deploy are human-only.
- Harness substrate does not gain AWS SDK/CLI dependencies.

## Verification

`npm run verify:harness` on this checkout: 251 tests passed.

## Outcome

Added `deployment/aws` at v14.9.0 with human-operated AWS docs. Substrate has no AWS SDK/CLI. Commit/PR pending human request.
