# IMP-20260804-01

## Request

Evolve v8 to v9 with SDD/TDD principles without duplicate systems, a Capability Layer, GitHub CLI HTTPS in place of GitHub MCP, and optional Context7 CLI instead of Context7 MCP.

## Approval

Approved by the user on 2026-08-04.

## Implemented

- Single existing state machine retained.
- Existing capability search and reuse/extend/replace/create decision added to planning.
- TDD Red/Green/Refactor added only as implementer discipline.
- Declarative capability manifest and validation added.
- GitHub integration migrated to `git` + `gh` HTTPS with approved push proposals.
- GitHub MCP and Context7 MCP assets removed.
- Chrome DevTools MCP retained as optional browser provider.

## Rollback

Revert ADR-0005 and this change set; no remote or credential mutation is performed by installation.

## Context7 CLI trigger amendment

Documentation requests are classified before provider selection. Context7 CLI is disabled by default and is invoked only when all manifest trigger conditions are satisfied. Its absence is non-blocking, and material conclusions require installed-version applicability plus official-primary-source verification.

## v8 operational fixes incorporated

Validated and incorporated five production-learned corrections from the v8 repository:

1. Canonical monthly worklog with agent/human contract and deterministic CLI.
2. Local-calendar worklog IDs instead of UTC-derived dates.
3. Required `external_evidence` and `diagnostic_evidence` keys for strict Codex structured outputs.
4. Removal of the nonexistent `github_readonly` MCP disable from the implementer launch command.
5. React Doctor comparison bases resolved from PR base SHA or push `before` SHA, normalized to immutable commits, with zero SHA rejection and no `HEAD^` CI fallback.
