# Improvement record: IMP-20260728-02

## Request

Improve the v8 harness so internal agent instructions cannot become public web
assets, while keeping the Public asset policy canonical and available to both
agent systems.

## Classification

- Type: security, generation integrity, packaging and documentation
- Scale: cross-cutting harness improvement
- Initial risk: high because internal instructions could become public assets

## Approved decision

- Remove generated instruction files from `public/`.
- Keep `harness/rules/public.md` as the single canonical Public asset role.
- Compose that role into root AGENTS for Codex and generate a scoped repository-
  level Cursor rule.
- Strengthen generator target validation and CI regression coverage.

## Implementation

See `docs/specs/PF-003-public-instruction-safety/` and ADR-0004.

## Verification

The canonical generator produced 50 synchronized outputs. Four new tests and all
37 previous tests passed for a total of 41. Public instruction targets, duplicate
replace outputs and path traversal are covered by deterministic checks.
