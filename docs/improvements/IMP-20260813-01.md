# CodeRabbit advisory review layer

- ID: `IMP-20260813-01`
- Status: `done`
- Date: 2026-08-13
- Owner: harness maintainer

## Problem

The existing CodeRabbit GitHub App has no version-controlled repository policy or formal boundary in the harness review pipeline, creating ambiguity about whether advisory findings can replace canonical verification or independent review.

## Proposal

Add root `.coderabbit.yaml`, document CodeRabbit as an optional advisory PR review layer, reuse existing instruction projections as Code Guidelines, exclude generated artifacts from ordinary review, and add dependency-free deterministic configuration tests.

## Acceptance

- `.coderabbit.yaml` is the sole repository-specific configuration source and contains no credential or `path_instructions`.
- Auto and incremental review are enabled for non-draft PRs, with request-changes workflow disabled.
- Deterministic verification, fresh read-only Codex final review, human approval, and lifecycle/evidence schemas remain unchanged.
- Core lifecycle remains operational when CodeRabbit is absent or unavailable.
